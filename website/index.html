PRIVACY IS AN ARCHITECTURE, NOT A SLOGAN

Local-first from input to export.

SignalDock keeps privileged browser capabilities at narrow boundaries and keeps analysis modules focused on the data you explicitly load.

01

No remote data path

The app CSP keeps connect-src 'none'. There is no telemetry endpoint, account service or analytics beacon in the runtime.

02

Explicit file capabilities

Local files are opened through user actions. File System Access capabilities stay in platform boundaries rather than leaking into analysis controllers.

03

Portable means portable

Workspace and case exports carry analysis state, not live file-handle capabilities. Case attachments are metadata-only references.

04

Bounded processing

Worker messages are authenticated with a per-session token, imports have explicit safety limits, and large export paths avoid one giant in-memory payload.

QUESTIONS BEFORE YOU LOAD A FILE

Local-first, without hidden assumptions.

SignalDock is intentionally explicit about what it can observe, what stays local and where browser capabilities begin and end.

Does SignalDock upload my logs?

No SignalDock backend is required for ordinary analysis. The shipped application CSP keeps connect-src 'none', and production audits reject runtime network primitives.

Do I need an account or API key?

No. Local log, trace, case and workspace workflows do not require a SignalDock account or API credential.

What happens when I save a workspace?

A portable .sdsession file is created through an explicit save action. Portable exports do not carry live browser file-handle capabilities.

Can SignalDock follow a changing local file?

Live Tail is available in supported browsers through an explicit local file capability. The file remains local to the browser session.

How are case attachments handled?

Case attachments are metadata-only references. SignalDock does not embed arbitrary attachment file contents into the Case Workspace record.

Is the website itself tracking visitors?

The bundled static website is script-free, uses no analytics runtime and carries the same no-connection CSP boundary.
