SECURITY

Small capability surfaces, explicit trust boundaries.

SignalDock keeps privileged browser, filesystem, storage and worker operations at narrow boundaries while domain and UI modules receive only the capabilities they need.

01

No application network path

The application CSP uses connect-src 'none'. Production audits reject fetch, XMLHttpRequest, WebSocket and EventSource primitives in runtime JavaScript.

02

Authenticated worker protocol

Background filtering uses protocol-v1 messages with an unpredictable per-session token, allowlisted message types, request/version checks and bounded envelope behavior.

03

Bounded local processing

High-volume paths use explicit caps, streaming scans, bounded result windows, histogram fallbacks or deterministic main-thread fallback rather than unbounded UI work.

04

No generic native bridge

The desktop capability facade is intentionally narrow. Controllers are not given generic shell, exec, spawn or arbitrary native invoke authority.

CAPABILITY BOUNDARIES

Feature code does not receive ambient authority.

The current architecture progressively moves feature behavior into zero-build controllers under src/app/. Storage, worker construction, filesystem access and cross-feature actions remain injected through explicit boundaries.

ISOLATED

Analysis modules

Trace, service, span and exception analysis modules operate on supplied data and do not own filesystem, network or persistence capabilities.

INJECTED

Application controllers

Controllers receive shared state, element registries and narrow callbacks instead of reaching directly into unrelated controllers or generic platform APIs.

PLATFORM

File capabilities

Browser save/open/reopen behavior is kept behind storage and desktop capability facades, with user permission required where File System Access applies.

VERSIONED

Worker boundary

The filter worker validates its protocol envelope and token before handling allowlisted index, filter, correlation and trace operations.

PORTABLE

Export boundary

Portable project exports strip file-handle capability keys, baselines omit raw logs and case attachments remain metadata-only.

ABSENT

Remote trust dependency

The shipped runtime does not depend on a SignalDock account server, hosted ingestion API, runtime CDN or analytics service.

ASSURANCE

Checks that ship with the repository.

The project runs repeatable quality gates around syntax, regression behavior, static architecture rules, local HTTP serving and CodeQL analysis.

Regression suite

Node-based smoke tests cover parser/query behavior, large-dataset scans, bounded ranking equivalence, filtered-scope semantics, accessibility contracts and feature-controller boundaries.

Static production audit

Static checks reject inline CSS/JavaScript, external runtime resources, missing local references, legacy branding and forbidden runtime network primitives.

CodeQL

The permanent CodeQL workflow analyzes JavaScript/TypeScript alongside the main quality gate. The repository keeps only the permanent CI and CodeQL workflows.

Dedicated workers: SignalDock authenticates worker envelopes with protocol version and a per-session token. A dedicated worker is not a cross-origin window message channel, so the security boundary does not rely on a window-style event.origin check.

RESOURCE SAFETY

Large datasets stay explicit and bounded where the UI has a natural cap.

Current main includes deterministic performance hardening without changing the observed result ordering of the affected views.

≋

Trace Explorer

Window ranking keeps only the requested offset plus limit instead of sorting the entire trace inventory when a bounded window is requested.

△

Trace Flame

Only the rendered span window is selected and sorted; large timing scans remain linear.

▦

♥

⌁

⚠

Final ranking is bounded to the requested result limit while the robust median/MAD baseline remains exact.

DEFENSE THROUGH BOUNDARIES

Keep privileged capabilities narrow.

SignalDock favors explicit local actions, deterministic analysis and audited limits over generic ambient authority.
