# SignalDock support

SignalDock is an open-source, local-first observability and investigation project.

## Before opening an issue

1. Check the current `README.md` and `docs/TECHNICAL.md`.
2. Confirm the problem still occurs on the latest `main` branch.
3. Search existing issues for the same behavior.
4. Reduce the problem to the smallest reproducible input you can.

## Protect your logs

Do not post production secrets, access tokens, passwords, personal information or confidential log payloads in a public issue. Use a minimal sanitized sample that preserves only the structure needed to reproduce the problem.

## Bug reports

Use the repository's **Bug report** issue form and include the SignalDock version, browser, operating system, reproduction steps and relevant sanitized console output.

## Feature requests

Use the **Feature request** form. Proposals should preserve SignalDock's local-first architecture and its rule that observed evidence must remain distinguishable from inferred or heuristic analysis.

## Security issues

Do not report vulnerabilities in a public issue. Follow `SECURITY.md` and GitHub's security-policy link for private reporting guidance.
